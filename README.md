# sherin.fun

The portfolio of **Sherin Varghese**, software engineer in Berlin. Live at [sherin.fun](https://sherin.fun).

A playful React site with 3D blocks, a project console, a CV printer that prints the CV with sound, and a contact form that emails through Google Apps Script.

## Projects shown on the site

- [Two Tone](https://app.sherin.fun): a demo drinks store (React, Express, MySQL) · [code](https://github.com/Red-Blue-co/Red-Blue)
- [ISU Student Community](https://isu.sherin.fun): a website for a student-run community · [code](https://github.com/Red-Blue-co/ISU)
- [QODE](https://qode.sherin.fun): circular hexagon codes you create and scan in the browser · [code](https://github.com/Red-Blue-co/qode)
- [og.sherin.fun](https://og.sherin.fun): live link-preview images · [code](https://github.com/Red-Blue-co/og)
- [Nex (sv-nex)](https://github.com/Red-Blue-co/Nex): a small Express framework

## Run it

```bash
npm install
npm run dev
```

`npm run build` writes the site to `dist/`, including a text snapshot of the page for search engines (`seo-prerender.js`).
